## 一、环境要求
- 一台装有 Windows 的电脑；
- 任一 MinGW-w64 的 g++（支持 C++17）。本机已验证：
  - `C:\mingw64\bin\g++.exe`
  - `D:\msys64\ucrt64\bin\g++.exe`

## 二、编译

**方式 1：双击一键脚本**
在资源管理器中双击 `build_windows.bat`，自动寻找 g++ 并生成 `sim_IMWRH.exe`。

**方式 2：命令行手动编译**
在源码目录打开命令行（PowerShell / cmd），执行：

```bat
g++ -std=c++17 -Wall main.cpp PlatformWRH.cpp UserWRH.cpp MicroAccountWRH.cpp ^
QQAccountWRH.cpp WeiboAccountWRH.cpp WeChatAccountWRH.cpp GroupWRH.cpp ^
QQGroupWRH.cpp WeChatGroupWRH.cpp FriendBookWRH.cpp GroupMemberBookWRH.cpp ^
MyDateWRH.cpp BaseInfoWRH.cpp -o sim_IMWRH.exe
```

若提示找不到 g++，请换成上面的完整路径，例如：
```bat
C:\mingw64\bin\g++.exe -std=c++17 -Wall main.cpp ...  -o sim_IMWRH.exe
```

## 三、运行

```bat
sim_IMWRH.exe
```

> 若界面出现中文乱码，先在命令行执行 `chcp 65001` 再运行即可
> （程序内部也已调用 `SetConsoleOutputCP(CP_UTF8)` 自适应）。

## 四、演示建议

1. 程序启动后显示“数字化主菜单”。
2. **直接输入 `1` 回车，即可观看“一条龙自动演示”**：
   - 开通管理（新用户可开通 N 个服务，QQ/微博同一主号，微信独立号并可绑定QQ）
   - 登录管理（一个服务登录 → 其它已开通服务自动登录）
   - 好友增/删/改/查
   - QQ 与微博“共同好友”
   - 微信添加“QQ 推荐好友”
   - 群管理全流程：QQ 群可申请加入、微信群只能被邀请/推荐；QQ 群有管理员制度、微信群仅群主特权；QQ 群可建临时讨论组、微信群不可以；踢人权限差异演示
   - 群管理模式动态切换（成员数据不受伤）
   - 数据总览
3. 演示结束后按 `0` 退出。退出时程序**自动把当前数据写回** `platform_data.txt`；下次运行时自动读入该文件（若删除该文件则重新使用固化演示数据）。
4. 其余菜单均为交互式子菜单，选择 **0 可返回上级**：
   - 2 用户管理（查看/开通/注销/登录/绑定）
   - 3 好友管理
   - 4 群管理
   - 5 数据总览
   - 6 文件读写演示（保存→用新实例读回，验证持久化）
