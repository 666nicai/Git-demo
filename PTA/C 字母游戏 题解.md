# C 字母游戏

- **平台**：PTA（吉林大学，作者：朱允刚）
- **分值**：30
- **限制**：代码 16 KB；时间 20 ms；内存 64 MB

## 题目描述

波比和哈丽在玩一个字母游戏，波比给出一个字符串 S，要求哈丽按照一定规则，基于该字符串算出一个数字 X。

规则是：

（1）求出 S 的最长重复后缀 P（P 是 S 的后缀且在 S 中出现大于 1 次，例如 `yacbacba` 的最长重复后缀是 `acba`）。

（2）求出在 S 中去除第二长相等前后缀（S 中所有相等的前缀和后缀中第 2 长者，例如 `abcabcxxxabcabc` 中最长相等前后缀是 `abcabc`，第二长的相等前后缀则是 `abc`）后剩下的子串 Q（例如 `abcabcxxxabcabc` 去除第二长相等前后缀后，剩下 `abcxxxabc`）。

则 X = P 的长度 + Q 的长度。

注意一个字符不能称为自己的前缀或后缀。子串 Q 至少为空串，其长度大于等于 0，不能为负数。

## 输入格式

输入为若干行，每行为一个字符串，包含不超过 100000 个字母。

## 输出格式

输出为若干行，每行一个整数，表示输入字符串所计算出的数字。

## 输入样例

```
abcabcxxxabcabc
xacbacba
abc
aaa
```

## 输出样例

```
15
12
3
3
```

## 题意拆解

对一个串 S（长度记为 n）：

- `|P|`：最长重复后缀的长度。后缀在 S 中至少出现两次（允许重叠，`aaa` 中 `aa` 出现在位置 0 和 1，算两次）。
- `b2`：第二长相等前后缀（即第二长 border）的长度。`Q = S[b2 .. n-1-b2]`，`|Q| = n - 2*b2`，为负时按 0 处理。
- 答案 `X = |P| + |Q|`。

两个子问题都可以 O(n) 解决。

## 子问题 1：最长重复后缀

直接枚举后缀是 O(n²)，需要转化。

### 关键转化：反转

设 `T = reverse(S)`。若 S 的长度为 l 的后缀在位置 p 再次出现：

```
S[p .. p+l-1] = S[n-l .. n-1]        (0 <= p < n-l)
```

两边同时反转，得到：

```
T[n-p-l .. n-p-l+l-1] = T[0 .. l-1]
```

即：**T 的前缀（长度 l）在位置 `q = n-p-l > 0` 再次出现**。反过来也成立。

所以：

> S 的最长重复后缀长度 = T 的最长重复前缀长度。

### Z 函数

`z[i] = LCP(T, T[i..])`，即 T 与从 i 开始的子串的最长公共前缀长度。`z[i] = l` 意味着 T 的长度为 l 的前缀在位置 i 又出现了一次。

因为前缀的另一次出现必须不在位置 0，所以：

```
|P| = max{ z[i] : i >= 1 }
```

Z 函数可以在 O(n) 内求出（维护当前最靠右的匹配区间 `[l, r)`，失败时利用已算出的 z 值跳过）。

## 子问题 2：第二长相等前后缀

相等前后缀就是 KMP 的 border。经典性质：

> 一个串的所有 border 都是它最长 border 的 border。

所以 border 长度层层嵌套成一条链：

```
b1 = pi[n-1]              // 最长 border
b2 = pi[b1-1]             // b1 这个前缀的最长 border，即 S 的第二长 border
```

（`pi` 是 KMP 前缀函数；`b1 = 0` 表示没有非空 border，此时 `b2 = 0`。）

### Q 的长度

```
|Q| = n - 2*b2
```

border 允许**自我重叠**：例如 `aaaaa` 的 border 链是 4、3、2、1，`b1 = 4, b2 = 3`，两端各删 3 个就重叠了（`2*3 = 6 > 5`）。题目特意说明"Q 至少为空串，其长度大于等于 0，不能为负数"，即：

```
|Q| = max(0, n - 2*b2)
```

## 参考代码

```cpp
// C 字母游戏（PTA 吉林大学）
#include<bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int z[100005],pi[100005];               // z:反串Z函数;pi:KMP前缀函数
    string s;
    while(cin>>s){                          // 若干行,每行一个字符串
        int n=s.size();
        string t(s.rbegin(),s.rend());      // 反串:最长重复后缀 -> 最长重复前缀
        z[0]=0;
        int mx=0;                           // mx:Z函数最大值,即|P|
        for(int i=1,l=0,r=0;i<n;i++){       // 标准Z函数,维护最右匹配区间[l,r)
            z[i]=(i<r)?min(r-i,z[i-l]):0;
            while(i+z[i]<n&&t[z[i]]==t[i+z[i]]) z[i]++;
            if(i+z[i]>r) l=i,r=i+z[i];
            mx=max(mx,z[i]);
        }
        pi[0]=0;
        for(int i=1;i<n;i++){               // KMP前缀函数
            int j=pi[i-1];
            while(j&&s[i]!=s[j]) j=pi[j-1];
            if(s[i]==s[j]) j++;
            pi[i]=j;
        }
        int b1=pi[n-1];                     // b1:最长相等前后缀
        int b2=b1?pi[b1-1]:0;               // b2:第二长相等前后缀
        int q=n-2*b2;                       // |Q|,两端重叠时可能为负
        if(q<0) q=0;                        // 题目要求非负
        cout<<mx+q<<endl;                   // X=|P|+|Q|
    }
    return 0;
}
```

## 样例验证

| S | `\|P\|` | `b1` | `b2` | `\|Q\|` | X | 期望 |
|---|---|---|---|---|---|---|
| `abcabcxxxabcabc` | 6 | 6 | 3 | 9 | 15 | 15 |
| `xacbacba` | 4 | 0 | 0 | 8 | 12 | 12 |
| `abc` | 0 | 0 | 0 | 3 | 3 | 3 |
| `aaa` | 2 | 2 | 1 | 1 | 3 | 3 |

## 复杂度

- 每个字符串：Z 函数 O(n) + 前缀函数 O(n)，总 O(n)。
- 空间 O(n)：两个 int 数组，各约 400 KB。
- 输入规模 10^5，在 20 ms 时限内没问题（关掉 `iostream` 同步、用全局数组避免反复分配）。

## 易错点

1. **Z 值只统计 `i >= 1`**：`z[0]` 是自己和自己，没有意义；只取 `i >= 1` 也正好保证是"另一处出现"。
2. **第二长 border 是 `pi[b1-1]`**：所有 border 都嵌在最长 border 里，不能随便取 `pi[n-2]` 之类的下标。
3. **`b1 = 0` 要特判**：没有非空 border 时，"第二长相等前后缀"按空串处理，`b2 = 0`，Q 就是整个 S。
4. **`|Q|` 要 clamp 到 0**：border 可以自我重叠，`n - 2*b2` 可能为负（如 `aaaaa`），题目要求长度非负。
5. **输入是"若干行"**：用 `while (cin >> s)` 逐词读，自动跳过空行和行尾 `\r\n`；样例输入末尾的空行正是这种情况。
6. **`P` 允许重叠出现**：`aaa` 的 `aa` 在位置 0、1 各出现一次，算"出现大于 1 次"。
