# A 二叉树的创建与遍历

- **平台**：PTA（吉林大学，作者：朱允刚）
- **分值**：20
- **限制**：代码 16 KB；时间 200 ms；内存 20 MB
- **源文件**：[A 二叉树的创建与遍历.cpp](A%20二叉树的创建与遍历.cpp)（题面嵌在文件头 `/* */` 注释里）

## 题目描述

通过带空指针信息的先根序列（即先序序列）创建二叉树，并进行先根（先序）、中根（中序）、后根（后序）遍历。二叉树结点数据域为不等于 0 的整数（可能是正数也可能是负数），空指针用 0 表示。例如 `1 5 8 0 0 0 6 0 0` 表示：

```
        1
       / \
      5   6
     /
    8
```

### 输入格式

输入为一组用空格间隔的整数，表示带空指针信息的二叉树先根序列。其中空指针信息用 0 表示。二叉树结点个数不超过 15000。输入数据保证二叉树各结点数据值互不相等。

### 输出格式

输出为 3 行整数，每个整数后一个空格。第 1 行为该二叉树的先根序列，第 2 行为中根序列，第 3 行为后根序列。

### 样例

输入：

```
1 5 8 0 0 0 6 0 0
```

输出：

```
1 5 8 6
8 5 1 6
8 5 6 1
```

（样例输出每题末数字后还有一个空格）

## 题意拆解

### 为什么加了 0 就能唯一还原树

单独一个先序序列（如 `1 5 8 6`）无法确定树形——`8` 到底是 `5` 的左孩子还是右孩子，序列里看不出来。补上空指针后，序列变成了树的**完整语法结构**：

- 每个非零数 = 一个结点，它后面**紧跟**两个东西：左子树的序列、右子树的序列；
- 每个 `0` = 一个空指针，它是递归的终点。

所以这个序列是递归定义的：

```
T = 0                                  （空树）
T = v  T_left  T_right                 （v ≠ 0）
```

于是建树就是把这段"递归的文本"逐字翻译成"递归的函数调用"：读一个数，非零就造结点，然后**紧接着**递归建左子树、再递归建右子树，指针自然回到下一个待读位置。消费顺序天然就是先序，这正是"先序序列"三个字的来历。

### 三种遍历只差"访问根"的时机

三者的递归骨架完全一样（左、右子树的划分方式相同），区别只在打印根结点的时机：

| 遍历 | 顺序 | 直观含义 |
|---|---|---|
| 先序 | 根 → 左 → 右 | 进来就先报自己 |
| 中序 | 左 → 根 → 右 | 左边处理完再报自己 |
| 后序 | 左 → 右 → 根 | 子树都处理完才报自己 |

把建树函数里的 `build()` 想成"处理一棵树"，遍历函数就是同一个递归结构换一下打印位置，所以三段代码可以几乎逐行对照着写。

## 关键点：输入怎么读

- **0 是唯一哨兵**，负数合法（`-1` 是结点，`0` 才是空），因此不能把"读到 0"当成结束条件。
- 树的中间也充满了 0，所以结束条件只能是**读到文件末尾（EOF）**。
- 推荐 `while (cin >> x)` / `if (!(cin >> x)) return nullptr;`；用 `scanf` 的话写 `while (scanf("%d", &x) != EOF)`，**不要**写 `while (scanf("%d", &x))` 之外的 `while (x)` 之类——`scanf` 返回的是成功读入的个数，读到一个值为 0 的数时返回值是 1，不会误判，但 `while (x)` 这种写法会。
- 输入可能被折成多行，`cin >>` 自动跳过所有空白，不用管换行。

## 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Node{
    int v;                      // 数据域
    Node *l,*r;                 // 左右孩子
    Node(int v):v(v),l(nullptr),r(nullptr){}
};

Node* build(){                  // 按带空指针的先序序列建树
    int x;
    if(!(cin>>x)) return nullptr;   // 输入结束
    if(x==0) return nullptr;        // 0 表示空指针,递归终点
    Node *p=new Node(x);
    p->l=build();                   // 紧接着的一段是左子树
    p->r=build();                   // 再紧接着的一段是右子树
    return p;
}

void pre(Node *p){              // 先根:根 左 右
    if(!p) return;
    cout<<p->v<<" ";
    pre(p->l);
    pre(p->r);
}

void in(Node *p){               // 中根:左 根 右
    if(!p) return;
    in(p->l);
    cout<<p->v<<" ";
    in(p->r);
}

void post(Node *p){             // 后根:左 右 根
    if(!p) return;
    post(p->l);
    post(p->r);
    cout<<p->v<<" ";
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    Node *root=build();
    pre(root);  cout<<"\n";     // 第 1 行:先根序列
    in(root);   cout<<"\n";     // 第 2 行:中根序列
    post(root); cout<<"\n";     // 第 3 行:后根序列
    return 0;
}
```

## 样例验证

序列 `1 5 8 0 0 0 6 0 0` 的读入过程：

```
1          → 根
  5        → 1 的左孩子
    8      → 5 的左孩子
      0    → 8 的左子树空
      0    → 8 的右子树空
    0      → 5 的右子树空
  6        → 1 的右孩子
    0      → 6 的左子树空
    0      → 6 的右子树空
```

树形即题面图。三种遍历：

- 先序：`1 5 8 6`
- 中序：`8 5 1 6`
- 后序：`8 5 6 1`

与样例输出一致。

## 复杂度

- 时间 O(n)：每个结点恰好建一次、每次遍历访问一次，三次遍历共 3n；
- 空间 O(n)：结点 15000 个，每个 16 B 左右，约 240 KB，远低于 20 MB；
- 递归深度 ≤ 树高 ≤ n = 15000，每帧几十字节，约 1 MB 以内，常见的 8 MB 栈足够。

## 易错点

1. **把 0 当结束符**：输入中间到处是 0，结束条件必须是 EOF，不是读到 0。
2. **负数**：数据可以是负数，判断空指针只能判 `x == 0`，不能判 `x <= 0`。
3. **输出格式**：题目要求每个整数后跟一个空格（包括行末最后一个），代码用 `cout << p->v << ' '` 正好符合；不要自作聪明去"省掉行尾空格"。
4. **建树顺序**：两个 `build()` 调用的先后就是左、右，写反了整棵树会镜像。
5. **空树**：如果第一个数就是 0（或输入为空），`root` 为 `nullptr`，三个遍历函数都会立刻返回，输出 3 个空行——`if (!p) return;` 这层防护不能省。
6. **栈深**：极端情况是 15000 深的单链，递归能过（约 1 MB 栈）；若把限制改到 10^6 级别，就需要改成显式栈的迭代版建树与遍历。
7. **内存泄漏**：本题直接 `new` 不 `delete` 也能过（进程退出即回收），但要养成习惯的话，可以写个 `destroy(root)` 后序释放。
