# B 艾迪的编码算法

- **平台**：PTA（吉林大学，作者：朱允刚）
- **分值**：20
- **限制**：代码 16 KB；时间 20 ms；内存 10 MB

## 题目描述

艾迪设计了一个字符串编码算法，把一个字符串 S 编码为另一个字符串，本题字符串中的字符均为 a~z 的小写字母。

他设计了一个函数 FS(c)，将该字符串 S 的某个字符 c 映射为另一个字符。该函数定义为：

```
FS(c) = chr(G(c, S))
```

其中 `G(c, S)` 表示字符 c 在字符串 S 中最后一次出现的位置后面不重复字符的个数。例如若 `S = "abcaedef"`，则 `G('a', S) = 3`，因为字符 'a' 在 S 中最后一次出现的位置是 3，该位置后有 4 个字符，但有 2 个 'e'，故不重复的字符为 3 个，即 'e'、'd' 和 'f'。函数 `chr(i)` 为第 i+1 个小写字母，例如 `chr(0) = 'a'`，`chr(1) = 'b'`，`chr(25) = 'z'`。故对于 `S = "abcaedef"` 有 `FS('a') = chr(G('a', S)) = chr(3) = 'd'`。

艾迪的编码算法即：依次将 S 中的每一个字符 c 替换为 FS(c)。例如 `"abc"` 对应的编码为 `"cba"`，因为 'a' 在字符串最后一次出现的位置后面有 2 个不重复的字符 'b' 和 'c'，故其 FS 值为第 3 个小写字母 'c'；'b' 在字符串最后一次出现的位置后面有 1 个不重复的字符 'c'，故其 FS 值为第 2 个小写字母 'b'；'c' 在字符串最后一次出现的位置后面有 0 个字符，故其 FS 值为第 1 个小写字母 'a'。同理，`"aacc"` 的编码为 `"bbaa"`，`"cac"` 的编码为 `"aba"`。

现给定一个字符串，请基于艾迪的算法编写程序，输出其编码后的字符串。

## 输入格式

输入为一个字符串 S。字符串长度不超过 10^5。字符串中的字符为 a~z 的小写字母。

## 输出格式

输出一个字符串，表示编码后的字符串。

## 样例 1

输入：

```
aca
```

输出：

```
aba
```

## 样例 2

输入：

```
bebcadcceedbcbe
```

输出：

```
babcedccaadbcba
```

## 题意拆解

对每个字符 c，`FS(c)` 只由两件事决定：

1. c 在 S 中**最后一次**出现的位置 `last[c]`；
2. **严格在该位置之后**的子串里，有多少个**互不相同**的字符，记为 `G(c)`。

然后 `FS(c) = 'a' + G(c)`（因为 `chr(i)` 就是第 i+1 个小写字母）。

最后把 S 的每个位置按 `S[i]` 的映射替换掉输出。注意是**替换**不是**链式替换**：输出第 i 位就是 `FS(S[i])`，直接用原始字符查表，替换后的字符不再参与映射。

## 关键观察

- `last[c]` 从左往右扫一遍、遇到就覆盖，最终留下的自然是最右（最后一次）的下标。
- `G(c)` 本质是"求 `S[last[c]+1 .. n-1]` 这段后缀里不同字符的个数"。字符集只有 26 个字母，"集合"可以直接用 **26 位整数的位掩码**表示：某位为 1 表示该字母在集合里，`popcount` 数出 1 的个数就是不同字符数。
- 后缀掩码可以递推：`suf[n] = 0`，`suf[i] = suf[i+1] | (1 << (S[i]-'a'))`。这样每个 `G(c)` 的查询是 O(1)。

## 算法

1. 左→右扫描，求 `last[26]`（初始 -1，表示未出现）。
2. 右→左扫描，求后缀掩码 `suf[n+1]`。
3. 对每个出现过的字符 c：`G(c) = popcount(suf[last[c]+1])`，`mp[c] = 'a' + G(c)`。
4. 按原串逐位查表输出。

总复杂度 O(n + 26)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();

    // last[c]：字符 c 在 S 中最后一次出现的位置
    int last[26];
    fill(last, last + 26, -1);
    for (int i = 0; i < n; i++) last[s[i] - 'a'] = i;

    // suf[i]：S[i..n-1] 中出现过的字符集合（位掩码）
    vector<int> suf(n + 1, 0);
    for (int i = n - 1; i >= 0; i--)
        suf[i] = suf[i + 1] | (1 << (s[i] - 'a'));

    // FS(c) = chr(G(c))，G(c) 是 last[c] 之后不同字符的个数
    char mp[26];
    for (int c = 0; c < 26; c++) {
        if (last[c] == -1) continue;
        int g = __builtin_popcount(suf[last[c] + 1]);
        mp[c] = char('a' + g);
    }

    for (int i = 0; i < n; i++) cout << mp[s[i] - 'a'];
    cout << "\n";
    return 0;
}
```

## 样例验证

样例 1 `S = aca`：

| 字符 | last | 之后的字符 | G | FS |
|---|---|---|---|---|
| a | 2 | （空） | 0 | a |
| c | 1 | a | 1 | b |

逐位替换：`a c a` → `a b a`，即 `aba`。

样例 2 `S = bebcadcceedbcbe`（下标 0–14）：

| 字符 | last | 之后的字符 | G | FS |
|---|---|---|---|---|
| a | 4 | dcc eedbcbe | 4（d,c,e,b） | e |
| b | 13 | e | 1 | b |
| c | 12 | be | 2 | c |
| d | 10 | bcbe | 3（b,c,e） | d |
| e | 14 | （空） | 0 | a |

逐位替换：`b e b c a d c c e e d b c b e` → `b a b c e d c c a a d b c b e` = `babcedccaadbcba`，与样例一致。

## 复杂度

- 时间 O(n + 26)：三次线性扫描 + 26 次 O(1) 查询；
- 空间 O(n)：`suf` 数组约 400 KB（`vector<int>`，元素连续存放）。

## 易错点

1. **必须是 `last[c] + 1` 开始的后缀**："位置后面"是严格之后；若从 `last[c]` 开始，会把字符 c 自己算进去，G 偏大。
2. **只需求出现过的字符的映射**：没出现过的字符 `last = -1` 直接跳过，输出时也不会用到。
3. **`mp` 对未出现字符未初始化是刻意的**：不会被读取，无需额外初始化（但不要写出读取未初始化元素的路径）。
4. **替换只做一遍**：输出时用原字符查表；不要拿替换后的字符继续查表（那就成了链式替换）。
5. **掩码与 `popcount`**：用 `int` 存 26 位足够；`__builtin_popcount` 是 GCC 内置函数，PTA 可用。
6. **输入**：串内无空格，`cin >> s` 直接读一行，自动跳过 `\r\n`。
