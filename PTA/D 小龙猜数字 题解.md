# D 小龙猜数字

- **平台**：PTA（吉林大学，作者：朱允刚）
- **分值**：30
- **规模**：字符串长度不超过 10^6；答案需用 `long long` 存储

## 题目描述

我们称一个字符串的秩为：该字符串长度减去该字符串的最短相等前后缀的长度。若该字符串不存在相等的前缀和后缀，则其秩为 0。

例如：`abcabcxabcabc` 最短相等前后缀为 `abc`，该字符串的秩为 10。

Pororo 和小龙玩猜字游戏，Pororo 给出一个字符串 S，小龙需计算 S 及 S 中所有前缀子串的秩之和。请编写程序帮助小龙猜数字。

## 输入格式

输入为 2 行，第 1 行为字符串 S 的长度，第 2 行为具体的字符串。字符串长度不超过 10^6。

## 输出格式

输出一个整数表示字符串 S 及其所有前缀的秩之和。

注：结果超出 int 型变量范围，请使用 long long 型变量。

## 样例 1

输入：

```
6
ababab
```

输出：

```
12
```

样例 1 解释：a 的秩为 0，ab 的秩为 0，aba 的秩为 2，abab 的秩为 2，ababa 的秩为 4，ababab 的秩为 4。

## 样例 2

输入：

```
10
bbcabbabbc
```

输出（截图被截断，按规则手算的结果）：

```
32
```

## 题意拆解

**秩的定义**：对任意字符串 T，

```
rank(T) = |T| - T 的最短非空相等前后缀长度
若 T 没有相等前后缀 → rank(T) = 0
```

注意是**最短**的，不是最长。验证题目例子：`abcabcxabcabc`（长度 13）的 border 有 `abc`（3）和 `abcabc`（6），最短是 3，秩 = 13 - 3 = 10。

要求：对 S 的每个前缀（长度 1 到 n，包含 S 本身）求秩，全部加起来。

## 核心推导

### 前缀的 border 是一条链

KMP 的前缀函数 `pi[i]` 给出前缀 `s[0..i]` 的最长真前后缀（border）长度。经典性质：**所有 border 都是最长 border 的 border**。所以前缀 i 的 border 长度构成一条嵌套链：

```
b1 = pi[i-1]      // 最长 border
b2 = pi[b1-1]     // 次长
b3 = pi[b2-1] ...
0                 // 退到空
```

"前缀 i 的最短非空 border"就是链上最小的非零元素。对每个 i 沿链退到底是 O(n²)（如全 `a` 串），需要递推。

### 最短 border 的递推

设 `mn[i]` = 前缀 i 的最短非空 border 长度（没有则 0）。前缀 i 的所有非空 border 分两类：

1. 最长 border 本身，长度 `b = pi[i-1]`；
2. 前缀 `b`（长度 b）的所有非空 border——border 的 border 还是 border。

于是：

```
b = pi[i-1]
b == 0        → mn[i] = 0（无相等前后缀）
b >  0        → mn[i] = mn[b] ? mn[b] : b
```

第二行含义：前缀 `b` 自己有更短的 border 就继承 `mn[b]`，否则 `b` 自己就是最短。由于 `b < i`，从左往右一遍就能算完。

### 秩与求和

```
rank(i) = i - mn[i]        （mn[i] 为 0 时 rank 直接为 0）
答案   = Σ rank(i), i = 1..n
```

答案上界约 `n²/2 ≈ 5×10^11`，必须用 `long long`。

## 参考代码

```cpp
// D 小龙猜数字（PTA 吉林大学）
#include<bits/stdc++.h>
using namespace std;
int pi[1000005],mn[1000005];            // pi:前缀函数;mn:最短非空border长度
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;string s;
    cin>>n>>s;
    n=s.size();                         // 以实际读入长度为准
    pi[0]=0;
    for(int i=1;i<n;i++){               // KMP前缀函数
        int j=pi[i-1];
        while(j&&s[i]!=s[j]) j=pi[j-1];
        if(s[i]==s[j]) j++;
        pi[i]=j;
    }
    long long sum=0;                    // 秩之和可达n^2,必须long long
    for(int i=1;i<=n;i++){              // i:当前前缀长度
        int b=pi[i-1];
        if(!b) continue;                // 无相等前后缀,秩为0
        int m=mn[b]?mn[b]:b;            // 前缀b有更短border就继承,否则b就是最短
        mn[i]=m;
        sum+=i-m;                       // 秩=长度-最短border
    }
    cout<<sum<<endl;
    return 0;
}
```

## 样例验证

样例 1 `S = ababab`，`pi = [0,0,1,2,3,4]`：

| 前缀长度 i | 前缀 | `b = pi[i-1]` | 最短 border `mn[i]` | 秩 |
|---|---|---|---|---|
| 1 | a | 0 | — | 0 |
| 2 | ab | 0 | — | 0 |
| 3 | aba | 1 | 1 | 2 |
| 4 | abab | 2 | 2 | 2 |
| 5 | ababa | 3 | `mn[3]=1` | 4 |
| 6 | ababab | 4 | `mn[4]=2` | 4 |

合计 `0+0+2+2+4+4 = 12`，与样例解释逐条一致。

样例 2 `S = bbcabbabbc`：

`pi = [0,1,0,0,1,2,0,1,2,3]`，各前缀的秩依次为 `0,1,0,0,4,5,0,7,8,7`，合计 `32`。

## 复杂度

- 时间 O(n)：前缀函数 O(n) + 一次线性 DP，所有指针移动均摊线性；
- 空间 O(n)：两个 `int` 数组各 10^6，共约 8 MB，必须放**全局**（局部数组会超出 8192 KB 的栈限制）。

## 易错点

1. **是最短 border，不是最长**：别套 C 题的"第二长相等前后缀"结论。
2. **无 border 时秩为 0**，不是字符串长度本身；空串不能算作相等前后缀，否则所有串的秩都会变成长度。
3. **结果用 `long long`**：题目明确提示超出 int 范围。
4. **`mn` 的下标是前缀长度**，`pi` 的下标是位置减一：`b = pi[i-1]`，读 `mn[b]` 时 b 是长度，两者不要混。
5. **数组放全局**：n 到 10^6，8 MB 的局部数组会爆栈。
6. 输入第一行给了 n，代码里仍用 `s.size()` 覆盖，避免两处不一致导致越界。
